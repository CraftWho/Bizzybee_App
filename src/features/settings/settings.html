Full save (backup & transfer)

Makes a full copy of your entire progress - every quest, DP, level, bee, everything - as one file. Nothing is removed from this device; it's a copy, not a move. Use it to keep a backup somewhere safe, or to bring your progress to another device. No account or internet connection needed.

Export Full Save

Downloads your complete Vault as one file. Send it to your other device however you like (email, Drive, AirDrop) and import it there.

A short numeric PIN is easier to remember and re-type on another device than a full password. Set a hint too if you're worried you'll forget it - the hint is saved in the file as plain, unencrypted text, so never put the actual PIN in it. You'll still need the exact PIN to import; there's no recovery if it's really lost.

Import Full Save

Loads a save file exported from another device. This replaces everything currently in this browser - make sure you actually want to overwrite it first.

Picker only offering Photos/Video? Look for a menu icon, "Browse," or "My Files" inside it. If the file was exported with a PIN, enter it above before importing.
