How to add it on Android
  1. Tap Add to Google Calendar (or open Google Calendar on a computer → Other calendars → + → From URL, and paste the link).
  2. On your phone, open Google Calendar → menu → Settings → 🐝 Bizzybee → turn on Sync.
  3. Changes show up within a few hours. Google sometimes takes up to a day.

Keep the link private. Anyone with it can see these items. Tap New link to cut off the old one.
