# BizzyBee for Steam Deck (Decky plugin)

Install: Deck, Desktop Mode or Game Mode. Decky settings -> Developer -> Install Plugin from ZIP -> pick `BizzyBee-decky.zip`.
Link: open BizzyBee in the Quick Access menu, tap Link, scan the QR with your phone (signed in), tap Link it.
Build: `npm install && npm run build`, then `bash make-zip.sh`.
